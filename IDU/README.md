This `dir` and its subs are for the IDU Firmware and other related files.<br>

The bin files are labeled as follows:<br>
`(idu)_(#)_(ver)_(oe/pf).bin`<br>
  - "oe" is for `.bin` files that have not used (to my knowledge) the "Reflash Mode" on the IDU.
  - "pf" is for IDUs the have used the "Reflash Mode" or ODUs that have been flashed by either the IDU or, if determined to be an option, by a user.<br>

[Known IDU](https://github.com/jbu313mlb92ome8w/Winegard-Trav-ler/wiki/Standard--IDU--Known) and [Known ODU](https://github.com/jbu313mlb92ome8w/Winegard-Trav-ler/wiki/Standard--ODU--Known) numbers do not correspond to each other unless there is a `@` with the numbers. See [IDU Wiki](https://github.com/jbu313mlb92ome8w/Winegard-Trav-ler/wiki/Standard--IDU) for more details.<br>
